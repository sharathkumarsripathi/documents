CHAPTER 1 - CLOUD CONCEPTS
Cloud benefits:
- Trade fixed expense for variable expense
- Economies of scale
- Stop guessing capacity
- Increase speed and agility
- Go global in minutes

Deployment models:
- Cloud: AWS-hosted
- Hybrid: AWS plus on-premises
- Private cloud: On-premises infrastructure

Well-Architected pillars:
1. Operational Excellence
2. Security
3. Reliability
4. Performance Efficiency
5. Cost Optimization
6. Sustainability

CHAPTER 2 - GLOBAL INFRASTRUCTURE
Region: Geographic location containing multiple Availability Zones.
Availability Zone: One or more isolated data centers.
High availability: Deploy across at least two Availability Zones.

Edge locations support CloudFront, Route 53, Global Accelerator and Shield.
Outposts: AWS infrastructure on-premises.
Local Zones: AWS infrastructure closer to users.
Wavelength: AWS compute near 5G networks.

CHAPTER 3 - SECURITY AND IAM
Shared responsibility:
AWS protects security of the cloud.
Customer protects security in the cloud.

IAM identities:
- User: Individual or application
- Group: Collection of users
- Role: Temporary permissions
- Policy: Permission rules

Use least privilege and MFA.
Explicit Deny always wins over Allow.
Do not use the root account for daily work.

Important security services:
IAM = access control
IAM Identity Center = workforce SSO
Organizations = multi-account management
KMS = encryption keys
Secrets Manager = secrets and rotation
CloudTrail = API audit logs
CloudWatch = metrics, logs and alarms
Config = configuration compliance
GuardDuty = threat detection
Macie = sensitive data discovery in S3
Inspector = vulnerability assessment
Shield = DDoS protection
WAF = filter web requests
Security Hub = central security findings
